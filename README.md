# Picsart TV

A static landing-page concept featuring microdramas, Unfold, Picsart News Desk, and a Microdrama Studio walkthrough with Spark.

## Hosting

GitHub Pages serves this repository from the root of the `main` branch. `.nojekyll` keeps it as a plain static site. No build or dependencies are required. Relative asset paths support a GitHub Pages project URL.

## Editing

- `index.html`: page content and accessible dialogs.
- `styles.css` and `brand.css`: layout, styling and Picsart font definitions.
- `app.js`: local preview interactions and screenshot walkthroughs.
- `reveals.js` and `reveals.css`: gentle one-time section entrances.
- `assets/`: artwork and supplied product screenshots.

Push changes to `main` to update the live page. Fonts load from the Picsart CDN.

This is an interactive concept preview. Live story generation, face insertion, episode playback and News Desk compilation are not connected. Product screenshots illustrate the separate apps; their pictured controls are not live controls.
